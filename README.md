# ![hoppr](https://i.imgur.com/Qg5ROP9.png)
A from-scratch OpenGL engine which renders original goldsrc `.bsp` maps for practicing kz, surf, and movement in general.

> **Status: WIP** (see: [Roadmap](#roadmap)).

## Focuses/Goals
- **Movement parity**: match the original half-life and goldsrc engine's movement
- **`.bsp` compatibility**: play and load classic `.bsp` maps

## Roadmap
- [x] `.bsp` rendering
- [x] auxillary `.wad` sourcing and processing 
- [x] transparent entity rendering
- [x] skybox rendering
- [x] custom shader support 
- [x] custom bindable inputs w/ configs
- [x] goldsrc base movement (bhopping, surfing, crouch jumping) 
- [x] ladder brush entity movement

- [ ] button brush entity interaction
- [ ] water movement
